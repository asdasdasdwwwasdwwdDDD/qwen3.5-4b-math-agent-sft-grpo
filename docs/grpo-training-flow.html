    摘视觉塔 · 冻结权重压 bf16纯文本用不到，省 ≈2 GB

    AdamW8bit + cosine非 paged，lr 1e-5，200 步计划

    ◆ 数据隔离：任务池 pool_train_v2.jsonl 经 probe 筛选（p∈[0.05,0.95] 有梯度信号），与 eval_v2 持出尺子零重叠。

  2. 1

    取任务难度感知采样器

    按各题成功率 p 的估计加权抽 2 题/步：太易（p→1）太难得不了梯度，中段题梯度信号最足。

    探索比例 0.5 ｜ 同题冷却 40 步 ｜ 同题最多抽 3 次 ｜ 全零组重抽 1 次（reroll-dead）｜ 难度表每步回写，续训不丢状态。

    ◆ 已修正（2026-11-23）：续训一度误用 probe 初版难度表，导致续训段 80% 重抽熟题；指向 difficulty_updated.json 后重抽率降到 29%。

  3. 2

    采样 Rollout每题 8 条完整解题轨迹

    ×2 题 ×8 轨迹
    生成一轮T=0.8 · 首 8 条批量 · 记 prompt/gen ids
    →
    解析 ```python 代码块
    →
    受限子进程真执行python -I · 超时 20s · 输出截断
    →
    执行结果 role="tool" 回填报错文本也回填

    ↺ 循环至 \boxed 终答或回合上限 · 每条 rollout 独立 MathEnv（2026-10-24 修复，勿回退）· 空 empty_cache

    ● 模板约定：执行结果必须以 role="tool" 回填（渲染成 ```output 包裹的 user 轮）——用裸 user 轮会让公共前缀 mask 把代码轮整个 mask 掉，只训终答不训代码。

  4. 3

    打分

    reward = 0.8 × \boxed 正确 + 0.1 × boxed 格式 + 0.1 × 执行无误　判卷用 math_env 同一把尺，训练与评测口径一致。

    做错但格式对、跑通不给零分（0.2/0.1 档），让"敢写敢跑"的行为先被奖励。

  5. 4

    组内优势

    adv = (r − 组均值) / 组标准差　比组内平均好为正，差为负。

    ● 组内全同分 → 优势全 0 → 零梯度步：v2 全程 18% 的步为零梯度，属正常现象；日志里 loss/kl 每步 ≈0 同理（μ=1 时 ratio 恒 1），学习信号看 grad_norm 与 success_rate。

  6. 5

    更新逐回合反传

    old当前权重，PPO 裁剪基准
    ref关掉 LoRA 的 SFT 模型，现场算 KL（β=0.05）
    act带梯度，真正反传的一次

    logits_to_keep 只对补全段出 logits（省 ~1.5GB）→ 回合损失按 token 加权 → 每 2 题 16 条轨迹优化一步 → 梯度裁剪

    ◆ μ=1（封存口径）：ratio 恒 1，PPO 裁剪退化为保险丝；--epochs 4 可切重放口径。

  7. 6

    记录 · 评估 · 续训

    每步写 jsonl + TensorBoard；每 20 步存 checkpoint，末尾存 final。

    best 机制：每 20 步在 40 题固定尺子上 greedy 闭环评估，最优存 out/best。续训三件套：--resume（挂 adapter）+ --init-step（步号偏移，TB 拼同一条线）+ --init-sched-steps（调度器快进，lr 逐位续接）。

    ● stop-drop 保险丝已关（2026-11-23 用户令）：0.05 阈值在 40 题尺子（σ≈8pp）上三次噪声误杀（每"次掉分"仅 3 题）。best 存档机制仍在，最终以 best + 新鲜终评为准。

v2 全程实测（200 步）：训练池 success 36%→52%（20 步窗口）；训练中评估 42.5→67.5→60→75.0（best@80）→后段 62.5–70 平台；新鲜 80 题终评 best@80 = 67.5%、final@200 = 66.2%（base 45.0%，+22.5pp）；全程 KL 累计 0.41 无跑飞；偷懒审计干净（做对题里"真算"占 91%，无跳代码/刷格式分倾向）。逐项明细见 outputs/eval/math_summary.md。
